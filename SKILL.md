# Назначение

Получить проверяемую расшифровку изображения. Общаться на языке пользователя; цитировать запись в оригинальной орфографии. Назначение — русское рукописное письмо разных исторических периодов. Первый этап наполнения и проверки — 1850–1950 годы. Для каждого документа учитывать его эпоху и тип письма; общий метод не означает проверенной точности для всех периодов. Для других эпох подбирать соответствующие образцы и явно указывать отсутствие валидации.

Это процесс чтения, не новая модель распознавания. Пока нет измеренных результатов, не обещать повышение точности.

# Работа с записью

1. Просмотреть фактическое изображение. Определить строки, колонки, переносы и достаточность разрешения. Название файла, индекс и семейное ожидание не заменяют изображение.
2. Сделать первоначальное чтение по видимым штрихам. Если известен ожидаемый ответ, учитывать риск подгонки; не называть такой проход слепым.
3. При неоднозначности прочитать [метод сравнения](references/reading-method.md). Найти ясные буквы и соединения у того же писаря на странице или рядом. Не считать одинаковым почерк всего архивного дела.
4. Для спорного имени, отчества, фамилии, возраста или формулы родства показать пользователю фрагмент с соседними словами и обозначить точное место. Дать различающие варианты только при графических основаниях; не составлять перечень подходящих по родословной имён. Если изображение нельзя показать, сказать об этом и запросить доступный фрагмент.
5. Ответить буквальной расшифровкой с обозначенными пропусками, затем при необходимости дать современную форму отдельно. Указать, что именно осталось неясным и на каких сравнениях держится чтение.

# Границы выводов

- Утверждение пользователя хранить как его чтение; не приписывать себе независимую проверку. При расхождении сохранять обе версии и основание разногласия.
- Отозванное чтение не возвращать в подтверждённый текст. Историю изменений хранить в существующем журнале дела, если пользователь разрешил запись; не создавать второй реестр.
- Подтверждённая расшифровка сама по себе не доказывает тождество людей или родство с исследуемой семьёй. Передавать результат в существующий генеалогический процесс вместе с источником и неопределённостью.
- Не дорисовывать буквы генеративными средствами. Увеличение, поворот и контраст могут помочь просмотру, но не создают отсутствующих деталей; сохранять исходник и различать производную.
- Использовать [каталог источников](references/sources.md) по необходимости. Пропись — учебная норма, а не доказательство чтения конкретного почерка. Чужие OCR-ответы не являются независимыми эталонами.
- Не отправлять приватные документы во внешние сервисы и не включать их в публичный репозиторий без отдельного разрешения на такую передачу.

# Проверка навыка

Для оценки результата использовать [процедуру](evals/README.md). Сценарии поведения не подменяют проверку распознавания по изображениям. Отличать структурную валидность навыка, успешное применение и измеренное улучшение.

# Справочная библиотека

При подборе аналогов читать [описание библиотеки](samples/README.md) и записи
`samples/records/`. Выбирать по периоду, типу письма и конкретному соединению;
сперва сравнивать ту же руку. Проверять `review.status`: предварительный образец
не является эталоном. Ссылаться на ID, страницу и область сравнения. Если подходящих
образцов нет, прямо указать пробел; не подменять их современным почерком.
Формат новых публичных образцов описан [отдельно](references/sample-format.md).
Добавлять пользовательский материал только по отдельному разрешению на публикацию.
