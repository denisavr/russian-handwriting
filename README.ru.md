# Russian Handwriting

Languages: [English](README.md) / [Русский](README.ru.md)

Навык для Codex и других ИИ-агентов: чтение и расшифровка русского рукописного письма разных исторических периодов.

**1850–1950 годы — первый этап наполнения и проверки**, чтобы быстрее применять навык к метрическим книгам, ревизским сказкам, актовым записям, письмам и делопроизводству. Затем охват расширяется на основе датированных образцов и проверок. Универсальное назначение не означает уже подтверждённой точности для всех эпох.

**Версия 0.2.0 — рабочий процесс чтения с небольшой проверенной библиотекой. Первый парный прогон не показал улучшения распознавания.** Это не обученная модель распознавания и не готовый атлас начертаний.

## Что он делает

- Сравнивает буквы и соединения с бесспорными словами того же писаря.
- Разделяет буквальную расшифровку, современное написание и толкование.
- Показывает существенные сомнения и не достраивает фамилии из ожидаемой родословной.
- Просит пользователя прочитать фрагмент с контекстом, если важная неоднозначность сохраняется.
- Сохраняет исправления и отменённые чтения с их статусом.

## Установка и использование

Склонируйте репозиторий в каталог навыков агента:

```sh
git clone https://github.com/denisavr/russian-handwriting.git ~/.codex/skills/russian-handwriting
```

Для других сред Agent Skills поместите папку в поддерживаемый каталог навыков. Установка не переобучает модель.

Пример: «Используй $russian-handwriting: прочитай запись и сравни спорное отчество с буквами того же писаря в соседних строках». Агенту нужен просмотр изображений. Навык сам не скачивает модели и не отправляет изображения в сторонние сервисы распознавания.

## Участие

Для образцов нужны дата, источник, надёжная расшифровка и явные условия распространения. Приватные документы и семейные сведения храните вне этой рабочей копии. Ответы активной проверки не должны быть доступны читающему агенту; опубликованные завершённые прогоны повторно не считаются слепыми. Спорное чтение не становится эталоном.

## Библиотека в разработке

См. [образцы и пределы покрытия](samples/README.md), [формат записей](references/sample-format.md) и [процедуру оценки](evals/README.md). Библиотека содержит три записи с визуальной проверкой сопровождающего репозитория, включая пять связных строк прописи. `python3 scripts/validate_samples.py` проверяет структуру и выводит инвентарь. [Первый парный прогон](evals/results/2026-10-29/README.md) охватывает только семь строк/полей; улучшение не показано.

## Открытый пример

Передайте изображение `samples/pages/strekoza-1880-letter.jpg` и попросите расшифровать только обращение в середине страницы. Проверенное сопровождающим чтение: **«Милостивый Государь!»**. Запись образца сохраняет источник, полную страницу, координаты, права и статус проверки. Остальной текст письма здесь не проверен.

Для необязательных проверок структуры и метрик нужен Python 3.9+ без сторонних пакетов; просмотр изображений обеспечивает сам агент. Если установленный скилл не появился в списке, обновите список навыков или начните новую сессию.
